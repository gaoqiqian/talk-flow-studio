# Review rubric and handoff

Score each dimension 0–2: 0 blocks delivery, 1 needs revision, 2 meets the intended brief. These are human review notes, not automatic marketing scores.

1. Story: hook is concrete, progression is clear, ending gives a useful next action.
2. Sync: graphics arrive on their spoken idea; critical names, numbers and labels are correct.
3. Information: each scene has a purpose, readable text and no unnecessary duplication.
4. Layout: stable alignment, face/gesture clearance, comfortable line spacing and phone-scale readability.
5. Motion: varied forms follow meaning, transitions have focus, no lengthy unintentionally static holds.
6. Evidence: actual screenshot/recording and illustrative content are clearly distinguished.
7. Technical: seek-safe timeline, checks inspected, expected duration/fps/audio, playable final output.

Revise all 0 scores and explain any unresolved 1. Do not imply the score proves superiority to another tool. If the user wants a comparison, use the same narration, duration and resolution; compare blind or with clearly stated criteria.

## Verification

- Validate plan intervals, relative paths, item cues and all scene/caption windows.
- Run HyperFrames check. Inspect its sampled timestamps; a skipped browser audit is not a passing visual audit.
- View actual entrance and settled frames. Layout escape attributes are only for deliberate layering or crops; never silence accidental clashes broadly.
- Browser layout checks do not detect a face hidden underneath an overlay. Inspect actual exported frames with the source visible, especially the widest graphic and speaker movement. Adjust speakerOffsetX or the panel layout and re-export when needed; check exposed edges and cropped gestures too.
- Proofread captions against speech: names, exam scores, websites and deliberate jokes need human review. Preserve intentionally repeated wording when it is part of the speaker's joke. Correct transcription text without inventing word timestamps; recheck changed cue boundaries.
- Inspect motion at normal speed around major transitions. Frames alone cannot prove pace or audio sync.
- Probe exported media: duration within one frame plus encoder rounding, expected dimensions and fps, H.264/AAC for a normal MP4 backup.
- Listen to start, middle and end. Metadata proving an audio stream exists does not prove intelligibility.

## Handoff files

Keep brief.md, transcript.json, optional cuts.json, plan.json, editable composition, asset-ledger.json and review.md in the project. Ledger entries contain local file, source/provenance, usage permission supplied by the user or applicable source, and whether the asset is actual evidence or illustration. Store no API credentials. An approved reference style is a preference, not a license to copy its music or copyrighted assets.
